# NOA競馬 — CYBER DERBY

時代を超えた名馬と、未来のサイバー競走馬が走る3D競馬ゲーム。

## 遊び方
GitHub Pages で公開すると、ブラウザだけで遊べます。

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://tomoonoa1439.github.io/noarace/` で遊べます

## 主な要素
- 実在の名馬（年代ミックス）が出走する3Dレースとオッズ・馬券（単勝〜3連単、ボックス・フォーメーション）
- 配合・育成・カードランク（F〜SSS）と覚醒
- レース介入（ネオンブースト・内を突け／外に出せ）
- パーツ改造（頭・背・コア）
- 特殊レース（月面・磁力レーン・障害ゲート）と6種類の会場テーマ
- 15種類のサイバー馬の個体

## セーブについて
GitHub Pages版のセーブデータは、遊んでいるブラウザの中に保存されます。
機種変更や別のブラウザに移るときは、右上のセーブボタンから「バックアップコード」をコピーして、移動先で復元してください。

## 構成
- `index.html` … ゲーム本体
- `three.min.js` / `GLTFLoader.js` … Three.js r128（MITライセンス）
- `assets/` … 馬の3Dモデル、カード・背景イラスト、装飾スクリプト
